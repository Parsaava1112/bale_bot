# 🤖 ربات بله با هوش مصنوعی

یک ربات پیام‌رسان **بله** که با زبان **پایتون** نوشته شده و از پایگاه داده، موتورهای هوش مصنوعی (پوشه `Ai_engine`) و سیستم پرداخت پشتیبانی می‌کند.  
این ربات قابلیت پاسخ‌گویی هوشمند، پردازش پرداخت و تعامل با کاربران را از طریق پیام‌رسان بله فراهم می‌کند.

## ✨ ویژگی‌ها

- 🧠 **موتور هوش مصنوعی ماژولار** – فایل‌های هوشمند در پوشه `Ai_engine` به راحتی قابل گسترش و جایگزینی هستند.
- 💾 **پایگاه داده** – ذخیره‌سازی اطلاعات کاربران، تراکنش‌ها و لاگ‌ها (SQLite یا MySQL طبق تنظیمات).
- 💰 **درگاه پرداخت** – اتصال به سیستم پرداخت بله با دریافت توکن اختصاصی از BotFather.
- 🔐 **مدیریت امن اطلاعات حساس** – استفاده از فایل `.env` برای نگهداری توکن‌ها و شماره موبایل.
- 📦 **وابستگی‌های مشخص** – تمام پکیج‌های مورد نیاز در `requirements.txt` لیست شده‌اند.
- ⚡ **اجرای سبک و سریع** – کاملاً مبتنی بر پایتون و کتابخانه رسمی بله.

## 📋 پیش‌نیازها

- **پایتون 3.8** یا بالاتر
- یک ربات ساخته شده در [BotFather](https://bale.ai/botfather) بله
- توکن پرداخت (در صورت نیاز به درگاه) از همان BotFather
- یک شماره موبایل فعال در بله (برای برخی قابلیت‌ها)
- ابزار `pip` برای نصب پکیج‌ها

## ⚙️ نصب و راه‌اندازی

### ۱. دریافت پروژه و ایجاد محیط مجازی

```bash
git clone https://github.com/your-username/bale-ai-bot.git
cd bale-ai-bot
python -m venv venv
# فعال‌سازی محیط مجازی:
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
۲. نصب پکیج‌های مورد نیاز
bash
pip install -r requirements.txt
۳. تنظیم متغیرهای محیطی (فایل .env)
یک فایل با نام .env در ریشه پروژه ایجاد کنید و مقادیر زیر را طبق اطلاعات ربات خود وارد کنید:

ini
BOT_TOKEN=your_bot_token_here
PHONE_NUMBER=09123456789
PAYMENT_TOKEN=your_payment_token_here
راهنمای دریافت توکن‌ها از BotFather:

ربات جدید: در پیام‌رسان بله، ربات @BotFather را جستجو کرده و دستور /newbot را اجرا کنید. نام و نام‌کاربری ربات را انتخاب کنید تا توکن بات دریافت کنید.

توکن پرداخت: برای فعال‌سازی درگاه پرداخت، در همان BotFather دستور /mybots را بزنید، ربات خود را انتخاب کرده، به بخش Payments بروید و یک پرداخت‌دهنده (مثلاً Stripe یا کارت‌به‌کارت) انتخاب کنید. توکن پرداخت را از آنجا کپی کنید.

نکته: توکن پرداخت فقط در صورتی نیاز است که ربات شما قابلیت پرداخت داشته باشد. در غیر این صورت می‌توانید مقدار PAYMENT_TOKEN را خالی بگذارید.

۴. پایگاه داده
روش کار:

در اولین اجرا، جداول مورد نیاز به‌طور خودکار ساخته می‌شوند (در صورت استفاده از SQLite).

فایل پایگاه داده در مسیر مشخص‌شده در تنظیمات (پیش‌فرض database/bale_bot.db) ذخیره می‌شود.

اگر می‌خواهید از MySQL/PostgreSQL استفاده کنید، باید رشته اتصال را در بخش تنظیمات (یا .env) تغییر دهید.

اطمینان حاصل کنید که دایرکتوری پایگاه داده وجود داشته و قابل نوشتن باشد.

۵. پوشه Ai_engine
پوشه Ai_engine/ حاوی ماژول‌های هوش مصنوعی است که هسته پردازش پیام‌ها را تشکیل می‌دهند. می‌توانید:

فایل‌های پایتونی مدل‌های آماده (مثلاً Hugging Face، GPT4All، ...) را در این پوشه قرار دهید.

یک کلاس پایه در فایل engine.py یا __init__.py وجود دارد که باید اینترفیس مشخصی (مثلاً generate_response(text)) را پیاده‌سازی کند.

برای استفاده از یک مدل خاص، کافی است کلاس مربوطه را در این پوشه تعریف و import کنید.

مثال ساده (در فایل Ai_engine/dummy_ai.py):

python
class DummyAI:
    def generate_response(self, user_message):
        return f"پاسخ هوشمند به: {user_message}"
سپس در فایل اصلی ربات، موتور فعال را براساس تنظیمات فراخوانی کنید.

▶️ اجرای ربات
پس از انجام تنظیمات، ربات را با دستور زیر اجرا کنید:

bash
python main.py
